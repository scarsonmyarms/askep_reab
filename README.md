# Кодування діагнозів реабілітаційного випадку

Програма читає довідник (Додаток до наказу НСЗУ, xlsx) і допомагає обрати основний та супутні діагнози
відповідно до формули кодування (стовпець O) і Правил (наказ НСЗУ № 182 від 16.04.2026).

## Встановлення
```
pip install openpyxl
```
tkinter входить до стандартного Python для Windows/macOS; у Linux: `sudo apt install python3-tk`.

## Запуск
Графічний інтерфейс:
```
python app.py шлях\до\довідника.xlsx
```
Командний рядок (без інтерфейсу):
```
python coding_rules.py довідник.xlsx --period post --main I63.3 --comp G81.9 --comp R47 --list
```
`--period post|long` — післягострий / довготривалий; `--st-required` — коди S/T у формулах T90–T95 обов'язкові;
`--list` — показати список для наступного супутнього поля.

## Логіка
- Основні — лише ті, що можуть бути основними (стовпець N) у вибраному періоді.
- Супутній 1 — за формулою основного; супутні 2–8 — за формулами основного та супутнього 1
  (плюс парні коди †/* уже обраних). Формула перевіряється лише для основного та супутнього 1.
- «плюс» — окрема обов'язкова група; «та/або» = «та» (кожна категорія — окрема обов'язкова група);
  «або» — достатньо одного з варіантів.
- Група вважається виконаною самим діагнозом, якщо він має відповідну категорію (I–M).
- Перевіряються: подвійне кодування †/*, несумісні поєднання (список `EXCLUSIONS` у `coding_rules.py`),
  повтори, збіг з основним. Діагноз поза довідником — коморбідний стан, у формулах не враховується.

## Тести
```
pip install pytest
pytest                                   # синтетичні тести (не потребують довідника)
pytest --xlsx=шлях\до\довідника.xlsx     # + регресійні тести на реальному довіднику
pytest -m "not gui"                      # без тестів інтерфейсу
```
Після запуску з реальним довідником у кінці виводиться розділ «Комбінації діагнозів, перевірені на реальному довіднику»
(основний, супутні, очікуваний і отриманий результат, причини ✖/⚠). Повний звіт по кожній комбінації: `pytest --show-reports`.
Лише тести довідника з назвами комбінацій: `pytest -m real -v`.

Реальний довідник також можна задати змінною середовища `REHAB_XLSX` або покласти `.xlsx` поруч з `app.py`.
